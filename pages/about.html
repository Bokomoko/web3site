Sobre o portal Bokomoko

Este é um portal descentralizado construído em JavaScript puro, sem frameworks. O conteúdo é endereçado por hash (CID), fixado na torrent cloud (BTFS) e espelhado no IPFS, e acessível por uma URL amigável via Unstoppable Domains (bokomoko.x).

Cada publicação gera um novo CID imutável. A URL amigável apenas aponta para o CID mais recente — versões antigas continuam acessíveis para sempre.
